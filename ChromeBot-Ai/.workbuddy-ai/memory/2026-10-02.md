## Project conventions (ChromeBot Ai)
- Version lives in two places that must match: `manifest.json` `"version"` and `core.js` `VERSION`.
- Tests: `tests/smoke.cjs` (controller/unit) + `tests/stream.cjs` (streaming regression, incl. reasoning-leak / truncation / late-done).
- UI layer is `ui.js` (CBUI); controller/agent loop is `panel.js`; shared stream/provider logic is `core.js` (global `globalThis.CBCore`).
- CSP-safe: model text is tokenised into DOM nodes, never assigned to `innerHTML`.
