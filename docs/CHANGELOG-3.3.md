# Orbit AI 3.3 — the agent can actually act now

This release fixes the bug that made the agentic bot unusable: **in the Chrome side
panel, `window.confirm()` is suppressed and silently returns `false`**. The agent's
per-step approval gate was a `confirm()`, so every proposed step — click, scroll, fill,
anything — was instantly "declined by you" and the run stopped. The agent could talk,
but never act. The same silent failure made conversation deletion and the page-tools
field write no-ops in the panel.

Sources: Chrome suppresses JavaScript dialogs in unfocused surfaces (a `confirm()`
generated by a page that is not the active tab never shows and answers `false` —
documented in chromium issue trackers and hit in the wild; see the GitHub report
"confirm() and alert() dialogs called via JS not working"). Orbit's panel is exactly
such a surface.

## What changed

- **`src/dialogs.js` (new)** — `askConfirm()`: a real `<dialog>` with Approve/Stop (or
  Delete/Keep) buttons, styled like the existing secret and hand-over dialogs. Works in
  the side panel, the floatable window and full tabs alike.
- **The agent gate is that dialog** (`askStepApproval`): the step description, the site
  origin and any tab legend appear in a scrollable detail box; **Approve step** runs it,
  **Stop the run** ends it. Tests inject the gate (`approve`) instead of mocking
  `window.confirm`, and a static gate bans `confirm(` from `app.js`, `agent-run.js` and
  `page-access.js` forever.
- **Deletions and the field write now really ask**: deleting a conversation or message
  and "Reset Orbit?" use the dialog (they silently did nothing in the panel before),
  and the Add-page "Replace the entire field?" write shows the replacement text in the
  dialog before writing.
- **Hands-free reading (opt-in)** — the pre-agreed answer to "make it automatic":
  Settings → Context → **Hands-free reading**. When on, a step whose actions are all
  read-only (snapshot, extract, scroll, hover, wait, screenshot, workspace list/read)
  runs without the dialog, and the transcript says so ("Read-only step ran without
  asking (hands-free reading is on)"). Anything that changes the page — clicks, typing,
  selection, Enter, navigation, tab switches, workspace writes, secrets, help
  hand-backs, memory saves — always asks, hands-free or not. Default: **off**.
